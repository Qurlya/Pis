Задание 5. Блочная модель (box model)

В задании №5 рассмотрена блочная модель элементов. Классу .box заданы ширина 240px, внутренние отступы padding 17px, рамка border 6px solid navy и внешний отступ margin 11px, итоговая ширина блока составила 286px. Блоку .box-a присвоен фоновый цвет teal, блоку .box-b — olive. Глобальным селектором * всем элементам страницы применено свойство box-sizing: border-box, после чего реальная ширина блока .box-b осталась равной заданным 240px, поскольку отступы и рамка включились в ширину элемента. Исходный код таблицы стилей представлен на листинге 5.

Листинг 5 – Блочная модель

/*
  ЛАБОРАТОРНАЯ РАБОТА №2
  ЗАДАНИЕ №5: Блочная модель (box model)
  Вариант 03
*/

/* --- Лёгкий уровень --- */

/* TODO 1: Свойства блока
   Общий класс .box — задайте width: 240px, padding: 17px,
   border: 6px solid navy, margin: 11px. Откройте в
   браузере и замерьте реальную ширину блока (например через DevTools,
   F12 → вкладка Elements → навести на блок). Запишите итоговую ширину
   в комментарии и посчитайте, почему получилось именно столько. */

/* Итоговая ширина блока: 286px.
   Расчет: 240px (width) + 17px (padding-left) + 17px (padding-right) + 6px (border-left) + 6px (border-right) = 286px.
   Margin (11px) не входит в видимую ширину самого блока, а создает внешний отступ. */
.box {
    width: 240px;
    padding: 17px;
    border: 6px solid navy;
    margin: 11px;
}

/* --- Средний уровень --- */

/* TODO 2: content-box (по умолчанию)
   .box-a оставьте как есть (box-sizing по умолчанию — content-box,
   его можно не писать явно). Просто добавьте background-color:
   teal, чтобы визуально отличать блоки друг от друга. */

.box-a {
    background-color: teal;
}

/* TODO 3: border-box
   .box-b — добавьте box-sizing: border-box и background-color:
   olive. Сравните в браузере реальную ширину .box-a и .box-b —
   у .box-b она должна получиться ровно 240px, несмотря на те же
   padding и border. Запишите в комментарии, почему так. */

/* Почему ширина 240px: При свойстве box-sizing: border-box значения padding и border включаются в общую заданную ширину (width).
Ширина области контента при этом автоматически уменьшается, поэтому итоговый размер элемента остается строго равен заданным 240px.
   (Примечание: само свойство box-sizing перенесено в глобальный селектор * ниже согласно TODO 4) */
.box-b {
    background-color: olive;
}

/* --- Сложный уровень --- */

/* TODO 4: Глобальный сброс
   Замените правило .box сверху так, чтобы box-sizing: border-box
   применялся сразу ко ВСЕМ элементам на странице через селектор *,
   а не только к .box-b. После этого свойство box-sizing можно убрать
   из .box-b — оно ему больше не нужно, оно и так унаследуется. */

}
